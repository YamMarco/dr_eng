"מה רוצים ממני?" |
| --- |
| המיקרו-סקיל:
Do you think? = YES/NO + 2 reasons + examples. 70-90 מילים. |
| --- |
| מסך 1 | WOW MOMENT |
| --- | --- |
| ❌ טעות נפוצה:

"Do you think teenagers should volunteer?"
תלמיד: "Volunteering is good. Many people volunteer."
← אין דעה. אין סיבות. |  | ✅ נכון:

"Do you think teenagers should volunteer?"
"Yes, I think... First... For example... In addition..."
← דעה + 2 סיבות + דוגמה. |
| --- | --- | --- |
| מסך 2 | THE TOOL — מה חשוב ומה פחות חשוב |
| --- | --- |
| 📊 כמה נקודות שווה דקדוק בכתיבה?


💡 גם עם דקדוק גרוע — אם התוכן נכון וברור, אפשר לקבל 22-25/30. |
| --- |
| 30 נקודות | מטלת הכתיבה = 30% מהציון. |
| --- | --- |
| 70-90 מילים | חובה. פחות מ-60 = מוריד נקודות. |
| Do you think? | תמיד דעה + הסבר. |
| Give reasons | לפחות 2 סיבות + דוגמה. |
| 💡 אוצר מילים בכתיבה:

מילים שלמדת בשיעורים 13-16 — השתמש בהן!
volunteer, community, environment, benefit, improve, responsible, society...
כל מילה "טובה" = ציון אוצר מילים גבוה יותר. |
| --- |
| 📋 נושאי הכתיבה שמופיעים ב-Module C:

🌍 סביבה: הגנה על הסביבה, זיהום, עצים, בעלי חיים
🤝 קהילה: התנדבות, עזרה לאחרים, שינוי חברתי
🏥 בריאות: ספורט, תזונה, בריאות נפשית
💻 טכנולוגיה: מסכים, אינטרנט, המצאות
📚 חינוך: בית ספר, שפות, כישורים לחיים

💡 כדאי להכין בבית 2-3 דוגמאות לכל נושא — לפני הבחינה. |
