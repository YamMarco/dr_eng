| מסך 1 | WOW MOMENT |
| --- | --- |
| 📈 מילות שינוי + חינוך + בריאות:

אלה הנושאים שחוזרים בטקסטים על חינוך, בריאות, ומדע.
ללמוד 15 מילים אלה = לקרוא בביטחון + לכתוב עם אוצר מילים טוב יותר.

💡 אוצר מילים = 8/30 בכתיבה. כל מילה שאתה יודע עוזרת! |
| --- |
| מסך 2 | THE TOOL — 15 מילות תוכן |
| --- | --- |
| מילה באנגלית | בעברית | בשאלה / בטקסט |
| --- | --- | --- |
| improve | לשפר | Students improved their results. |
| develop | לפתח | We develop new skills. |
| achieve | להשיג | Students achieved better grades. |
| affect (v) / effect (n) | להשפיע / השפעה | Noise affects sleep. The effect is serious. |
| cause | לגרום / סיבה | Stress causes health problems. |
| education | חינוך | Education is important for success. |
| health / healthy | בריאות / בריא | Exercise keeps people healthy. |
| skill(s) | מיומנות/ות | Volunteering develops useful skills. |
| opportunity | הזדמנות | This is a great opportunity. |
| responsible | אחראי/ת | Students became more responsible. |
| require | לדרוש | The programme requires two years. |
| benefit | יתרון / להפיק | One benefit is better health. |
| encourage | לעודד | Teachers encourage students. |
| support | תמיכה / לתמוך | The programme supports families. |
| society | חברה | This helps society as a whole. |
