| 📋 SECTION 3 — PART II: WRITING TASK (30 Points)

Question 9 — The Writing Topic:

"In your opinion, what changes can be made to your school so that it can become a better place to learn? Give reasons to explain your opinion."

לדעתך, אילו שינויים אפשר לעשות בבית הספר שלך כדי שיהיה מקום טוב יותר ללמידה? תן/י סיבות להסביר את דעתך.

• Write 70–90 words in English.
• Give your OPINION — say what you think should change.
• Give REASONS — explain WHY each change will help. |
| --- |
| ⚡ שים לב — זה שונה מ-"Do you think?":


💡 אותם ביטויים — מבנה שונה קצת. THE TOOL מסביר הכל. |
| --- |
| מסך 2 | THE TOOL — מבנה שאלת "What changes?" |
| --- | --- |
| שלב | מה כותבים | ביטוי פתיחה |
| --- | --- | --- |
| 1️⃣ פתיחה | 1-2 משפטים — הצג נושא + דעה כללית | "In my opinion, there are two important changes..." / "I think that schools can be improved in two ways..." |
| 2️⃣ שינוי 1 | תאר שינוי ראשון + למה יעזור | "First, I think we should have... This would help because..." |
| 3️⃣ שינוי 2 | תאר שינוי שני + למה יעזור | "Also, I believe... Another change is... For example..." |
| 4️⃣ סיכום | משפט אחד | "In conclusion, I am sure that these changes will help students." |
| 💡 ביטויים שימושיים לכל שלב: |
| --- |
| 📊 זכור — הרוברוקה:
תוכן = 10 | אוצר מילים = 8 | דקדוק = 8 | כתיב = 4. פחות מ-60 מילים = קנס! |
| --- |
| מסך 3 | WATCH IT — דוגמת תשובה מנותחת |
| --- | --- |
| "In your opinion, what changes can be made to your school so that it can become a better place to learn?" |
| --- |
| 1️⃣ פתיחה | In my opinion, there are two important changes that can make school a better place to learn. |
| --- | --- |
| 2️⃣ שינוי 1 | First, I think we should have shorter lessons and more breaks. Students often feel tired after sitting for a long time, so short breaks help them concentrate better. |
| 3️⃣ שינוי 2 | Also, I believe schools should have more computers and technology in classrooms. This would make lessons more interesting and help students learn in new ways. |
| 4️⃣ סיכום | In conclusion, I am sure that these changes will help all students enjoy school more and learn better. |
| ✅  ~80 מילים ✅ | דעה ✅ | שני שינויים ✅ | סיבות לכל שינוי ✅ | סיכום ✅ |
| --- |
| 💡 שים לב: "This would make lessons more interesting" = vocabulary טוב → ציון גבוה יותר. |

| מסך 4 | TRY IT — השלם עם הביטויים הנכונים |
| --- | --- |
| נושא: "What changes can be made to improve your neighborhood?"

השלם כל שלב: |
| --- |
| 1️⃣ פתיחה | In my opinion, there are ___________ that can make my neighborhood better. |
| --- | --- |
| 2️⃣ שינוי 1 | First, I think we should have ___________. This would help because ___________. |
| 3️⃣ שינוי 2 | Also, I believe we should ___________. For example, ___________. |
| 4️⃣ סיכום | In conclusion, I am sure that these changes will ___________. |
| ✅ דוגמת תשובה:
"In my opinion, there are two important changes. First, I think we should have more parks and green areas. This would help because people need fresh air and a place to relax. Also, I believe we should have better public transport. For example, more buses would help people travel easily. In conclusion, I am sure that these changes will improve life for everyone."
~65 מילים — מוסיפים עוד משפט קטן ומגיעים ל-70. ✅ |
