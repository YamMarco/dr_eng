| מסך 1 | WOW MOMENT |
| --- | --- |
| 💸 כמה נקודות אבדו בגלל מילה אחת?

"Give ONE answer from paragraph II."

תלמיד ידע את התשובה.
הוא כתב אותה — מהפסקה הנכונה.
אבל כתב שתי תשובות במקום אחת.
ציון: 0 נקודות. |
| --- |
| 📋 מה עוד קרה לתלמידים אחרים?

✗ כתב תשובה מפסקה III כשביקשו מפסקה II ← 0
✗ לא הבין "according to" וענה כלל לא נכון ← 0
✗ "complete the sentence" — כתב תשובה חדשה ← 0

כל הטעויות — מ-10 מילים שלא ידעו. |

| מסך 2 | THE TOOL — 10 מילות השאלה |
| --- | --- |
| מילה באנגלית | בעברית | בשאלה / בטקסט |
| --- | --- | --- |
| paragraph | פסקה | Read paragraph II and answer. |
| according to | לפי | According to Dr. Klein, what... |
| explain / explains | מסביר | What does the text explain? |
| give ONE answer | תן תשובה אחת | Give ONE answer from paragraph I. |
| complete the sentence | השלם את המשפט | Complete: People leave because... |
| circle the correct answer | הקף את התשובה | Circle the correct answer: i ii iii iv |
| give TWO answers | תן שתי תשובות | Give TWO answers from paragraph III. |
| because | כי / מפני ש | Complete: They left because... |
| in order to | כדי ל | They came in order to... |
| what do we learn | מה אנחנו לומדים | What do we learn from paragraph I? |
| מסך 3 | WATCH IT |
| --- | --- |
| שאלה: "What do we learn from paragraph I about Redonda?"
ניתוח: "what do we learn" = מה לומדים | "paragraph I" = לך רק לפסקה 1 |
| --- |
| שאלה: "According to Dr. Green, give ONE answer: why do trees die?"
ניתוח: "according to Dr. Green" = לפסקה שלו | "give ONE" = תשובה אחת בדיוק. |
| --- |
| שאלה: "Complete the sentence: People left because..."
ניתוח: "complete" = יש התחלה, אני מסיים אותה מהטקסט — לא כותב תשובה חדשה. |
