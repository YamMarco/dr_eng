| שיעור 03
"P1 — נוסחת הניווט" |
| --- |
| המיקרו-סקיל:
שאלה → מילת מפתח → אתר → קרא → ענה. חמישה צעדים. |
| --- |
| מסך 1 | WOW MOMENT |
| --- | --- |
| 😰 הרגע הכי קשה בבחינה:

"פתחת את הדף. 200 מילים באנגלית. לא מכיר מילה אחת. הלב נופל."

מה עושים? |
| --- |
| ❌ מה שרוב התלמידים עושים:

"מנסים לקרוא ולהבין הכל."
"נתקעים. פאניקה."
"שוכחים לכתוב." |  | ✅ מה שצריך לעשות:

לא קוראים את הטקסט.
קוראים רק את השאלה הראשונה.
מחפשים מילת מפתח.

"לא מבין את הטקסט" ≠ "לא יכול לענות". |
| --- | --- | --- |
| 💡 הסוד:
אתה לא צריך להבין את הטקסט. אתה רק צריך למצוא את המילה שהשאלה מבקשת.
P1 עובד גם כשהטקסט קשה — כי אתה מחפש, לא קורא. |
| --- |
| מסך 2 | THE TOOL — P1 |
| --- | --- |
| שלב 1 | 📖 קרא את השאלה עד הסוף — לא את הטקסט. |
| --- | --- |
| שלב 2 | 🔍 מצא מילת מפתח — המילה שתחפש בטקסט. |
| שלב 3 | 🎯 אתר את המילה בטקסט — כמו חיפוש בוואטסאפ. |
| שלב 4 | 📝 קרא רק את המשפט שמכיל את המילה. |
| שלב 5 | ✅ ענה — מהטקסט בלבד, לא מהראש. |
| 💡 מילת המפתח:
בדרך כלל השם החשוב. לא "what", "how", "why" — אלה מילות שאלה.

"Why did the scientists start the project?" ← מילת מפתח = "scientists" / "project" |
| --- |
| מסך 3 | WATCH IT — P1 בפעולה |
| --- | --- |
| I Every year, forests around the world are destroyed by fire, farming, and pollution. However, there is good news. In 2019, a group of scientists started a project to plant one billion trees in Africa by 2030. The project, called Green Africa, has already planted over 200 million trees in 15 countries.

II The project is led by Dr. Amara Diallo, a scientist from Senegal. "We do not just plant trees," says Dr. Diallo. "We teach local people how to care for them." According to Dr. Diallo, most trees die because nobody looks after them. When local people are involved, 85% of trees survive.

III The results are already visible. In Ethiopia, the number of birds increased by 60% in areas where trees were planted. In addition, in Kenya, rivers that were dry for 20 years began to flow again. Scientists say that if the project continues, it could reduce carbon in the atmosphere by 15%. |
| --- |
| ❓ השאלה:
According to Dr. Diallo, why do most trees die? |
| --- |
| שלב 1 | קורא השאלה: "לפי ד'ר דיאלו, למה רוב העצים מתים?" |
| --- | --- |
| שלב 2 | מילות מפתח: "Dr. Diallo" + "trees die" |
| שלב 3 | מחפש "Dr. Diallo" בטקסט — פסקה II. |
| שלב 4 | "most trees die because nobody looks after them." |
| שלב 5 | תשובה: Because nobody looks after them. |
| ✅  Because nobody looks after them. |
| --- |
