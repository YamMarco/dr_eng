| TEACHER OVERVIEW — L21

LESSON 21  —  Reason + Explanation + Example
The 3-part structure: Reason + Explanation + Example
Template: because ___ / This means ___ / For example ___

Objective
By the end of this lesson the student writes 2 reasons with explanation and example for any exam writing topic using the fixed 3-part template.
Key insight
"A reason without explanation is weak. An explanation without an example is abstract. The 3-part template — Reason + Explanation + Example — gives the student a sentence formula they can apply to any topic. Once they have it, writing 70–90 words becomes mechanical, not creative."
Timing plan

Common mistakes to watch for
· Student writes reason but skips explanation: "I think X because it is good." — good is not an explanation
· Student writes reason and explanation but uses a personal example: "For example, I once..." — avoid first person examples when possible
· Student writes 3 reasons but no explanation for any — depth beats breadth in this exam
· Student confuses reason and example: a reason EXPLAINS why; an example SHOWS it |

| 25–35 min | WE DO — guided practice |
| --- | --- |
| TEACHER — WE DO
WE DO: write the first full reason together on the board.
"I think that teenagers should have a part-time job because it teaches them real-life skills."
"This means that teenagers develop responsibility and learn to manage money."
"For example, many students who work part-time become more organised in school."
Count words. Ask: "Is this ONE reason? Yes. How many sentences? 3." |
| --- |
| WE.  Together: write the SECOND reason using the same template. Same topic.
"Another reason is that ___. This means ___. For example, ___." |
| --- |
| ANSWER KEY
Sample: "Another reason is that working gives teenagers useful experience for the future. This means that they are better prepared for adult life and can find jobs more easily. For example, many employers prefer to hire young people who have already had work experience."
3 sentences = 1 reason. Two reasons = 6 sentences minimum = about 60 words. |

| 3.  Write 2 full reasons using the template. Topic: "Is there too much emphasis on tests and grades in our education system?"
Reason 1: I think ___ because ___. This means ___. For example, ___ .
Reason 2: Another reason is ___. This means ___. For example, ___ . |
| --- |
| ANSWER KEY
Sample: "I think there is too much emphasis on tests because they measure only one type of intelligence. This means that creative and practical students often perform poorly despite being talented. For example, a student who is excellent at art or sport may fail a written exam. Another reason is that tests cause serious stress. This means that many teenagers feel anxious during exam periods. For example, studies show that stress affects sleep and concentration." (80 words — perfect!) |

| TEACHER — HOMEWORK
Homework (15–20 min):
1.  Write 2 × R+E+E on: "Which language would you like to learn?" Time yourself: 12 minutes.
2.  Practice the template 5 times with different topics. The template must become automatic.
3.  Write your "example bank": 5 general examples that work for any topic:  "Many students..." / "For example, a teenager who..." / "Studies show..." / "In many schools..." / "According to experts..."
4.  Prepare for L22: read your L21 paragraph. Can you improve the example in reason 2?
