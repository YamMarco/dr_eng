| מסך 1 | WOW MOMENT |
| --- | --- |
| 🔴 מה קורה כשתלמיד לא מכיר מילת תוכן:

"In 2016, a group of environmentalists decided to make Redonda green again."

תלמיד עוצר: "environmentalists? מה זה?"
הוא מנסה לתרגם. לא מוצא. מדלג. מאבד הקשר.
שאלה 3 מתייחסת למשפט הזה. הוא לא יכול לענות.
8 נקודות אבדו — בגלל מילה אחת. |
| --- |
| ✅ מה קורה כשמכירים אותה:

"environmentalists" ← זה מהמילה "environment" + "-ists" = אנשים שעוסקים בסביבה.
הוא זיהה ← הבין ← ענה ← 8 נקודות. |
| --- |
| 💡 המילים בשיעור הזה מופיעות ב-90% מהטקסטים.
ללמוד אותן = לקרוא בביטחון — בלי לעצור. |
| --- |
| מסך 2 | THE TOOL — 15 מילות תוכן |
| --- | --- |
| מילה באנגלית | בעברית | בשאלה / בטקסט |
| --- | --- | --- |
| environment | סביבה | The environment is under threat. |
| volunteer(s) | מתנדב/ים | Many students volunteer. |
| community | קהילה | The local community helped. |
| discover / found | גילה / מצא | Scientists found that stress fell. |
| result(s) | תוצאה/ות | The results were surprising. |
| increase | לגדול / לעלות | The number increased by 60%. |
| reduce / decrease | לקטון / לרדת | This could reduce pollution. |
| protect | להגן | Laws protect the forests. |
| destroy | להרוס | Forests are destroyed every year. |
| species | מין (ביולוגי) | Many species are at risk. |
| charity | ארגון צדקה | A local charity started the project. |
| residents | תושבים | 85% of residents are satisfied. |
| researchers | חוקרים | Researchers found the results. |
| affect | להשפיע על | Noise affects concentration. |
| effective | יעיל | The most effective programme... |
| מסך 3 | WATCH IT |
| --- | --- |
| מצא ועגל מילות תוכן:

"A local charity decided to change the environment. The results were remarkable. Residents said stress levels fell." |
