| TEACHER OVERVIEW — L17

LESSON 17  —  5 Connectors + Error Clinic
because / however / also / for example / in addition
Find and fix — the 5 most common writing errors

Objective
By the end of this lesson the student uses the 5 key connectors correctly and fixes the most common errors in their own writing.
Key insight
"Connectors are the skeleton of a paragraph. Without them, sentences are isolated. A student who writes "Volunteering is good. It builds skills. For example, teamwork." has 3 correct sentences. A student who connects them with "because", "also", "for example" writes a paragraph."
Timing plan

Common mistakes to watch for
· Student writes "Because I like sport." — because cannot start a standalone sentence
· Student writes "However, but I think..." — never use however AND but together
· Student writes "for example that" — "for example" is followed by a noun or clause, not "that"
· Student confuses "also" and "although" — also = adds information; although = contrast
· Student writes "In addition to" without a following noun — "In addition, I think..." |

| Word | Hebrew | In a question | Why it matters |
| --- | --- | --- | --- |
| because | כי / מפני ש | ...because it teaches skills. | Because + subject + verb. NEVER "because + noun" alone. |
| however | אולם / אבל | However, some students disagree. | However + comma. Starts new sentence. NEVER "however but". |
| for example | לדוגמה | For example, many students volunteer. | For example + noun/clause. NEVER "for example that". |
| in addition / also | בנוסף / גם | In addition, working builds confidence. | In addition = formal. Also = informal. Both add information. |
| although | למרות ש | Although it is hard work, it is worth it. | Although = contrast inside ONE sentence. Different from "however". |
| 15–45 min | Connectors + Error clinic |
| --- | --- |
| Connector | Grammar rule | Wrong | Correct |
| --- | --- | --- | --- |
| because | Subject + verb BEFORE and AFTER | Because sport is fun. | I like sport because it is fun. |
| however | New sentence. Comma after. | However but I disagree. | I agree. However, I think... |
| for example | Noun or clause after — no "that" | For example that many students... | For example, many students... |
| in addition | Start new sentence. Comma after. | In addition to volunteering... | In addition, volunteering... |
| although | One sentence only. Contrast inside. | Although. I disagree. | Although it is hard, it is useful. |
