| TEACHER OVERVIEW — L24

LESSON 24  —  Error Analysis + Final Repair
Score → Which pattern failed → Targeted practice → Final Exam Toolkit

Objective
By the end of this lesson the student has identified their personal weakest pattern, practised it, and has the Final Exam Toolkit ready for the real exam.
Key insight
"The student who looks honestly at what went wrong in L23 and repairs it will perform better in the real exam. This lesson is about honesty, not shame. Every pattern can be fixed. One focused session is more valuable than re-reading the whole course."
Timing plan

Common mistakes to watch for
· Student focuses on their overall score rather than which pattern failed
· Student wants to fix everything — direct them: ONE pattern first
· Student skips the toolkit because "I know all of this" — the toolkit is for exam day nerves
· Student has not memorised the P14 template — this must be automatic |

| The 3 things to do in the FIRST 3 minutes of the exam:
1.  Skim topic sentences of each paragraph (30 seconds).
2.  Read ALL questions before reading the text carefully.
3.  Circle Eye Catchers in each question (numbers, names, NOT).

For each question:
P8: Am I at GREEN? → Traffic Light check.
P1+P9: Question → Keywords → Locate → Read → Answer → Evidence.
P15: Hard question? Mark → Move → Return at minute 60.

For the writing task:
P14: YES/NO (30 sec) → Reason (because ___) → Explanation (This means ___) → Example (For example ___) → Second reason → Count words (70–90).

The 5 most dangerous mistakes:
1. Missing NOT in a question → P4: hunt for FALSE.
2. Stopping at one answer in a two-correct question → P11: keep looking.
3. Freezing on a hard question → P15: mark and move.
4. Writing under 70 words → add one sentence to each reason.
5. Answering before reaching GREEN → P8: check first. |
