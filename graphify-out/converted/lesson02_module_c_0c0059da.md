| שיעור 02
"Traffic Light" |
| --- |
| המיקרו-סקיל:
לפני שאני עונה — האם אני יכול להסביר את השאלה בעברית? |
| --- |
| מסך 1 | WOW MOMENT |
| --- | --- |
| 📋 סיטואציה אמיתית מבחינת בגרות:

"Question 3: According to Dr. Klein, explain what she found in her study."

תלמיד קורא. "ידעתי!" הוא חושב. כותב: "She found that adults learn faster."
ציון חזר: 0 נקודות.

מה קרה?
השאלה ביקשה מה היא מצאה בתוך המחקר שלה. הוא ענה על מה אחרים אמרו.
מילה אחת שלא הבין — "explain" — גרמה ל-0. |
| --- |
| 💡 הפתרון: Traffic Light + מילון חכם.
לפני שעונה: האם אני יכול להסביר את השאלה בעברית? לא? ← מילון לשאלה. |
| --- |
| מסך 2 | THE TOOL — רמזור + מילון |
| --- | --- |
| 🔴
לא מבין.
← עצור. |  | 🟡
מבין חלקית.
← בדוק שוב. |  | 🟢
יכול להסביר
בעברית.
← עונה! |
| --- | --- | --- | --- | --- |
| 📖 מילון — מתי ואיך:

✅ מתי להשתמש: כשמילה בשאלה לא ברורה → מילון.
✅ לא צריך: מילים בטקסט שאינך מכיר — בדרך כלל אפשר להתעלם מהן.
⚠️ מגבלת זמן: מקסימום 30 שניות למילה אחת. לא מוצא? ← P15 — M ועובר הלאה.

❌ אל תחפש: "paragraph", "according to", "give ONE" — אלה בשיעור 13. ללמוד אותן בעל פה. |
