| מסך 1 | WOW MOMENT |
| --- | --- |
| 🎯 P14 = נוסחת הכתיבה שלך:


YES/NO

↓ I think that... because...

↓ This means... / For example...

↓ In addition,...

↓ In conclusion, I believe that... |
| --- |
| מסך 2 | THE TOOL — P14 + זכור |
| --- | --- |
| מילה באנגלית | בעברית | בשאלה / בטקסט |
| --- | --- | --- |
| I think / I believe that | אני חושב/ת שׁ | I think that volunteering is important. |
| because | כי | ...because it develops useful skills. |
| This means that | זה אומר ש | This means that students learn to work. |
| For example | לדוגמה | For example, many students volunteer. |
| In addition | בנוסף | In addition, it improves mental health. |
| Another reason is | סיבה נוספת | Another reason is that it helps society. |
| In conclusion | לסיכום | In conclusion, I believe that... |
| 💡 על דקדוק בכתיבה — להרגע:

דקדוק שווה 8/30 נקודות. תוכן שווה 10/30 נקודות.
הרעיון שלך חשוב יותר מהמשפט המושלם.

מה שחשוב לכל משפט: subject + verb. זה הבסיס.
שאר הדקדוק — ייבוא. הכתוב + הנושא = הציון שלך. |
| --- |
| מסך 3 | WATCH IT — דוגמה מלאה עם תיוגים |
| --- | --- |
| "Do you think teenagers should volunteer in their community?" |
| --- |
| 🔵 YES/NO | "Yes, I think that teenagers should volunteer in their community." |
| --- | --- |
| 🟢 סיבה 1 | "First, volunteering develops important skills." |
| 🟡 דוגמה | "For example, many teenagers learn to work in a team and become more responsible. This means they are better prepared for the future." |
| 🟢 סיבה 2 | "In addition, volunteering is good for mental health." |
| 🟡 דוגמה | "Studies show that young volunteers feel less stressed and sleep better." |
| 🔵 סיכום | "In conclusion, I believe that volunteering has many benefits for teenagers and for society as a whole." |
