| מסך 1 | WOW MOMENT — כמה נקודות שווה דקדוק? |
| --- | --- |
| 📊 הנה הרוברוקה הרשמית של משרד החינוך: |
| --- |
| 💡 מה זה אומר לתלמיד?

✅ תוכן טוב + 70-90 מילים = עד 18/30 גם בלי דקדוק
✅ דקדוק "minimally correct" = 5/8 — עדיין מקבל!
⚠️ מקסימום הפסד על כתיב = 2 נקודות בלבד
❌ פחות מ-60 מילים = עולה יותר מהפסד דקדוק!

המסקנה: כן ללמוד דקדוק — אבל לא לפחד ממנו.
subject + verb בכל משפט = הבסיס שמגן עליך. |
| --- |
| מסך 2 | THE TOOL — שני כללי ברזל |
| --- | --- |
| כלל 1: כל משפט = subject + verb.
"Students volunteer." ← ✅
"Many teenagers jobs." ← ✗ חסר פועל |
| --- |
| כלל 2: יחיד/רבים.
I / He / She / It + verb+s: "She volunteers."
We / They / Students + verb: "They volunteer." |
| --- |
| 💡 קריאה vs כתיבה:

📖 קריאה: דקדוק שגוי בתשובות → לא מורידים נקודות. מה שחשוב: המידע מהטקסט.
✏️ כתיבה: דקדוק → 8/30. subject+verb = הבסיס שמגן עליך. |
| --- |
| מסך 3 | WATCH IT |
| --- | --- |
| תקן:

❌ Many students jobs. → ✅ Many students have jobs.
❌ Students is responsible. → ✅ Students are responsible.
❌ I was think it good. → ✅ I think that it is good.
❌ The teenagers need time. → ✅ Teenagers need time.
❌ Because sport healthy. → ✅ ...because sport is healthy. |
