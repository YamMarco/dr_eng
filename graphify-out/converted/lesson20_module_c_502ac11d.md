| שיעור 20
"70-90 מילים — תרגול בזמן" |
| --- |
| המיקרו-סקיל:
70-90 מילים. לא 60. לא 100. סופר כל פעם. |
| --- |
| מסך 1 | WOW MOMENT |
| --- | --- |
| ❌ 55 מילים:

"Yes, I think volunteering is good. It helps health. For example, students feel better. In conclusion, important."
← 55 מילים. חסר 15. מאבד נקודות. |  | ✅ 76 מילים:

"Yes, I think teenagers should volunteer. First, it develops important skills. For example, teenagers learn to work in a team. This means they are ready for the future. In addition, it helps mental health. Volunteers feel less stressed. In conclusion, volunteering is very beneficial."
76 מילים ✅ |
| --- | --- | --- |
| מסך 2 | THE TOOL — ספירה + טבלת קנסות |
| --- | --- |
| 📊 כיצד לספור:

כל מילה = 1. "a", "the", "and" — גם נספרות.
"I think (2) that (3) volunteering (4) is (5) important (6)."

שיטה:
כתוב → ספור → כתוב מספר בסוף → בין 70-90? |
| --- |
| ⚠️ טבלת קנסות רשמית — משרד החינוך:


💡 מינוס 6 נקודות על 45 מילים = יותר יקר מכל שגיאת דקדוק! |
| --- |
| מסך 3 | WATCH IT |
| --- | --- |
| ספור מילים:

"Yes, I think that protecting the environment is very important. First, we need clean air and water to stay healthy. For example, in many cities, pollution causes serious health problems. In addition, protecting the environment helps animals and plants to survive. In conclusion, I believe that every person should do something to help the environment."

____ מילים |

| ✅  68 מילים — קצת פחות מ-70. הוסף: "...every single person should try to do something small." ← 75 מילים ✅ |
