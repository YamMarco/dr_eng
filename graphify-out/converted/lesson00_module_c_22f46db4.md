| מסך 2 | THE TOOL — שני עקרונות |
| --- | --- |
| 📦 מה זה THE TOOL?

בכל שיעור יש מסך THE TOOL — הכלי שלך.
זה לא הסבר שקוראים ושוכחים.
זה משהו שמשתמשים בו — ב-TRY IT ו-YOUR TURN.

כשרואה THE TOOL → קרא → שמור בראש → השתמש. |
| --- |
| הם מתחילים לקרוא מהמילה הראשונה.
מנסים להבין הכל. נתקעים. הפאניקה מתחילה.
אחרי 10 דקות — עדיין בפסקה 1. לכתיבה לא נשאר זמן. |
| --- |
| 1   הטקסט שם — התשובה כתובה בתוכו. לא צריך אנגלית מושלמת.
2   לא צריך להבין הכל — רק למצוא את מה שהשאלה מבקשת. |
| --- |
| 💬 זכור:
"אני מחפש, לא קורא."
