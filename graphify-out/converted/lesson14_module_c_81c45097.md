| מסך 1 | WOW MOMENT |
| --- | --- |
| 🚦 Eye Catchers הם סימנים שאומרים לך לאן ללכת:

however / but / although ← פנייה. מה שאחריו חשוב.
NOT / NEVER / NO ← ציד. מחפש מה שקרי.
most / only / main / first ← הגבלה. תשובה ספציפית.
in addition / also ← עוד מידע בא.
because / therefore ← סיבה/תוצאה. |
| --- |
| מסך 2 | THE TOOL — 12 מילות ניווט |
| --- | --- |
| מילה באנגלית | בעברית | בשאלה / בטקסט |
| --- | --- | --- |
| however | אולם / אבל | However, not all types are the same. |
| although / but | למרות ש / אבל | Although it was free, nobody came. |
| NOT / NEVER / NO | לא / אף פעם | Which is NOT true? |
| most / only | רוב / רק | The most effective programme... |
| main / first | עיקרי / ראשון | What is the main reason? |
| in addition | בנוסף | In addition, stress levels fell. |
| therefore / as a result | לכן / כתוצאה | Therefore, birds returned. |
| because / since | כי / מאחר ש | Because nobody cared for them. |
| for example | לדוגמה | For example, in Ethiopia... |
| according to | לפי | According to scientists... |
| increase / decrease | עלה / ירד | The number increased by 60%. |
| found / discovered | גילה / מצא | Researchers found that... |

| I Learning to swim as an adult is more common than many people think. According to a recent survey, over 30% of adults in large cities cannot swim. Many of them feel embarrassed about this and never try to learn. However, experts say it is never too late.

II One study found that adults who learned to swim later in life often became stronger swimmers than those who learned as children. "Adults understand what the teacher explains and can correct their mistakes more quickly," says Dr. Anna Klein. "They are also not afraid to ask questions."

III Adult swimming classes are now available in most cities. Some programs meet only once a week, while others offer three sessions a week. According to instructors, adults who practice regularly usually make good progress in less than two months. |
